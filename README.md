# Communication Studio

基于 **C# 14 / .NET 10 / WPF** 的工业通信调试工作台。首版以真实通信会话、明确的生命周期和可控的实时显示为基础，支持多个端点同时在线。

## 运行

环境：Windows 10/11，.NET 10 SDK。`global.json` 固定稳定版 10.0.201 SDK，允许同 feature band 的补丁升级。使用 Visual Studio 时需要支持 .NET 10 的版本和「.NET 桌面开发」工作负载。

```powershell
dotnet run --project src/Communication.App
```

也可以打开 `CommunicationStudio.slnx`，将 `Communication.App` 设为启动项目。Release 构建后可运行：

```text
src/Communication.App/bin/Release/net10.0-windows/CommunicationStudio.exe
```

构建和验证：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1
```

测试是无需测试框架包的可执行集成测试程序，以非零退出码报告失败；不是 `dotnet test` 项目。除串口使用 `System.IO.Ports 10.0.0` 外，没有额外运行依赖。

CAN 提供独立的 `ICanSession` / `CanFrame` 扩展契约，但 **没有硬件驱动实现或可连接的 CAN 选项**。数据库历史、曲线和自定义解析器尚未实现。

端点管理中的「端点」表示一项可配置的通信资源，包括串口、TCP 客户端、本地 TCP 监听器或 UDP 绑定。连接、断开、重连和远端关闭等词继续表示通信生命周期，避免将 UDP 绑定或监听器配置等同于已建立的 TCP 连接。

右键端点卡片可开启、关闭或移除端点，卡片右上角的 `×` 可直接移除。菜单操作针对右键所在的卡片；在线端点移除前会停止其周期发送并释放通信资源，其他端点继续运行。正在开启或关闭的端点暂时不能移除；被 Modbus 占用的端点与临时 Modbus 端点需先在 Modbus 页面停止。

端点名称可以留空：名称输入框显示由传输类型和地址生成的默认名称水印，列表、日志和发送端使用默认显示名称，配置仍保存空名称。对端筛选列表和接收端上拉列表使用可匹配的端点名称，鼠标悬停显示地址；接收端选中后显示名称，内部保留地址和 TCP 客户端标识进行路由。外部端点或无法唯一匹配的地址保留地址显示，避免猜测设备身份；同名端点仍按所选地址区分。已接入本软件 TCP Client 的服务端可通过其实际本地套接字地址识别名称。搜索同时匹配名称和地址。

端点与 Modbus 的 IP 输入框支持可编辑下拉列表：绑定地址提供全部本地网卡（`0.0.0.0` / `::`）及回环（`127.0.0.1` / `::1`），TCP 远端提供回环地址和 `localhost`。选项展示语义说明和实际地址，选择后保存实际地址，仍可手动输入。UDP 接收端也提供与发送端地址族匹配的回环及 IPv4 广播目标，沿用当前接收端端口；广播为 `255.255.255.255`，仅在用户选择并执行发送后发送报文。

通信监控的列顺序为时间、I/O、端点、对端、字节和数据。「对端」在 TX 时表示接收方，在 RX 时表示发送方；串口不能自动识别远端设备，显示 `—`，原始记录仍保留本地串口信息。发送区左上角的格式菜单默认 HEX；选择文本后通过子菜单选择编码。字节数、周期发送和行尾选项集中在右侧发送按钮旁，窄窗口自动换行。编码发送不附加 BOM，不能表示的字符会报错，避免静默替换为问号；切换格式保留编辑内容。

UDP 设置区只显示本地「绑定」，IP 和端口分别标注；端点列表也显示本地绑定地址。通用发送区的「发送端」上拉菜单列出 ONLINE 且未被 Modbus 占用的端点，独立于侧栏选择；所选端点关闭后清除发送端，需主动重新选择。UDP「接收端」上拉菜单列出其他 UDP 配置，也可直接输入外部 `host:port`，IPv6 使用 `[地址]:端口`；本机通配绑定转换为回环地址作为发送目标。TCP Server 接收端列出已接入客户端，手动输入地址必须匹配唯一已接入客户端，不会新建出站连接；串口和 TCP Client 接收端不可编辑。各发送端保留各自的接收目标，周期发送固定启动时的发送端、接收端和编码后数据。行尾选项仅在文本模式下显示。下方标签栏右侧的箭头可隐藏整个内容区域，为通信监控腾出空间，再次点击恢复原高度、选中标签和输入内容；通信不会停止。

发送端也可选择「当前端点」，跟随侧栏选中的端点。该选项在端点离线时仍保留，发送和周期发送按钮禁用；开启后自动允许发送。选择具体 ONLINE 端点时继续独立于侧栏，关闭后清除具体发送端。周期发送仍固定启动时的源和目标。文本模式的行尾设置位于周期发送间隔左侧。

IP 下拉列表还会在每次展开时后台发现当前启用网卡的 IPv4 / IPv6 单播地址，显示网卡名称和地址，包括无线、有线与虚拟接口；IPv6 链路本地地址保留接口作用域。原有特殊地址、手动输入和当前填写的值仍保留，发现失败不影响输入。端点与 Modbus 的本地、远端 IP 选择器共用此行为。

## 快速体验

1. 选择 **TCP listener**，本地 IP 改为 `127.0.0.1`，端口选择一个空闲端口（如 `23570`），点击「监听」。
2. 选择 **Local TCP client**，远端使用 `127.0.0.1` 和同一个端口，点击「连接」。串口和 UDP 的启动按钮显示「开启」，所有传输类型统一使用「关闭」停止。
3. 输入文本并发送。Traffic 中应出现客户端 TX 与服务端 RX，二者字节内容相同。
4. 在发送区选择监听器作为发送端，再从接收端上拉列表选择已接入客户端后发送，可验证反方向的数据。
5. 选中数据行，在「报文详情」查看完整内容；取消 HEX 可查看 UTF-8 文本。
6. 为 UDP 选择空闲本地端口，将远端设为该本地端口，可进行自发自收。

功能菜单切换端点管理和 Modbus 管理视图；工具菜单打开独立校验码计算窗口。工具窗口右上角的固定图标默认启用置顶，点击可取消；再次打开激活已有窗口，关闭后保留计算输入和结果。主窗口关闭时工具窗口也关闭。

快捷键：`Ctrl+N` 新建端点；`Ctrl+S` 保存端点配置；`Ctrl+Enter` 发送；`Ctrl+L` 清空流量显示；`Ctrl+F1` 切换端点管理；`Ctrl+F2` 切换 Modbus 管理；`Ctrl+1` 打开校验码工具。功能使用 `Ctrl+Fn`，工具使用 `Ctrl+数字`，按菜单顺序编号。

在菜单「外观」中切换深色 / 亮色主题，在「语言」中切换中文 / English，立即生效。表格、输入框、横纵滚动条、菜单、悬浮筛选列表和寄存器对话框使用同一套主题；语言切换包含固定界面文案、状态、日志类型和 Modbus 报文字段。切换保留活动连接、选中报文、筛选和待编辑值，不翻译用户输入的端点名称或发送内容。主题和语言选择原子保存到 `%LocalAppData%/CommunicationStudio/appearance.json`，下次启动恢复；损坏或未知配置回退到深色中文。系统提供的异常详情沿用操作系统语言。

界面样式集中在 `Themes/Dark.xaml`，两套颜色分别在 `DarkPalette.xaml` 和 `LightPalette.xaml`；固定文案在 `Localization/zh-CN.xaml` / `en-US.xaml`，动态诊断和报文字段的翻译短语在 `Localization/catalog.json`。本地化只作用于显示绑定，不改变导航标识、筛选值或协议模型。

通信监控的「时间」表头显示上下排序箭头，点击切换升序 / 降序，默认升序；「跟随」在两种排序下都定位到最新记录。右键「I/O」「端点」「对端」表头打开多选筛选列表，可全选或清空选择；「端点」菜单包含「当前端点」，「数据」菜单包含搜索，筛选框在表头上方弹出并实时更新结果，启用筛选的表头高亮。「当前端点」启用时，端点菜单其余控件禁用并暂不使用手动端点多选，取消后恢复原选择；对端菜单的「当前对端」按选中报文的对端地址筛选，同样禁用手动多选并保留原选择，刷新清除报文选择时仍保留当前对端地址；I/O、对端和搜索仍共同生效；选项来自当前保留的记录，清空通信监控会重置多选表头筛选。端点名称悬停显示源端点地址，对端名称悬停显示对端地址；名称和地址不随界面语言翻译。

## Modbus 管理

默认端口 `1502`，Unit ID `1`，与原始端点管理会话独立运行。

Modbus TCP 从机开始监听、RTU 主机打开串口或 RTU 从机启动后，会同步到端点管理。已有同一串口或冲突 TCP 本地监听地址的端点显示红色「已占用」，禁用连接与发送区；没有对应配置时显示临时 Modbus 端点，该记录由 Modbus 管理负责操作，不会保存进连接配置。停止、关闭或 RTU 事务失败释放端口后解除占用并移除临时记录。TCP 客户端的远端地址、UDP 本地端口不作为 TCP 监听占用处理。

这些端口的实际读写同时进入端点管理的 Traffic、报文详情和 TX/RX 统计。同步不依赖本软件发起请求：外部客户端、串口设备、错误 CRC、其他从站地址或不完整数据都会按实际读取片段显示，TCP 保留真实对端地址；TX 在写入成功后记录。RTU 主机空闲期间也会接收并监控外部数据，使用事务互斥避免抢读预期响应。Modbus 页面仍按完整协议报文显示，端点管理显示底层读取片段，两者不能以记录条数直接比较。统计独立于显示队列，暂停显示或队列丢弃不停止计数；多个端点配置引用同一个端口时，全局计数不重复累计。

1. 进入「Modbus 管理」，协议选择「Modbus TCP」，点击「从机模式」，本地 IP 保持 `127.0.0.1`，点击「启动从机」。
2. 新建保持寄存器分区，配置起始偏移与数量；从机表格自动加载。双击「写入值」单元格输入十进制或 `0x1234`，点击「应用写入值」。
3. 点击「主机模式」，主机端点配置为同一个地址和端口，点击「读取数据表」即可回读。
4. 主机可写入选中行或批量写入表格；Coils 和 HoldingRegisters 可写，DiscreteInputs 与 InputRegisters 通过协议只读。从机本地可编辑所有四类表，用于模拟输入数据。
5. 「开始轮询」固定启动时的端点、表类型和范围；「停止轮询」取消在途请求。切换到从机模式会停止轮询；切换到主机模式不会停止正在监听的从机，便于同机验证。

位表读取最多 2000 项，寄存器读取最多 125 项；批量写线圈最多 1968 项、保持寄存器最多 123 项。各表偏移范围为 0–65535。从机支持最多 32 个客户端，每个完整请求限时 30 秒；不匹配的 Unit 返回异常码 0x0B。从机数据及 Modbus 页面参数目前在内存中维护，重启后重新配置。表格中未应用的编辑值会保留，便于比较实时值和待写入值。

HEX 示例：`01 03 00 00 00 02 C4 0B`。HEX 只接受成对十六进制字符和空白，不自动附加行尾或 CRC。

### Modbus RTU

停止从机和轮询、关闭已打开的 RTU 串口后，可在左侧参数面板顶部切换协议。选择「Modbus RTU」，填写或发现串口名称，配置波特率、校验位、停止位和响应超时。数据位固定为 8，默认 9600 / Even / One，超时默认 1000 ms。主从机分别保存串口参数：主机打开 COM1 后，从机仍可选择 COM2 并同时运行。选择被另一角色占用的串口时，名称下方仅显示红字「已占有」。打开串口失败时弹出对话框说明失败原因；选择或切换页面不弹窗。切换页面保留各角色连接，正在运行的角色参数保持锁定，另一角色参数可以编辑。

- 主机模式：配置从站地址（1–247），点击「打开串口」，然后读取、单项/批量写入或轮询。串口在事务之间保持打开；「关闭串口」取消在途请求并释放端口。超时、取消或帧校验失败会关闭串口，需要手动重新打开；标准 Modbus 异常响应不会关闭连接。
- 从机模式：配置本机从站地址并点击「启动从机」。沿用四类表和寄存器分区编辑；支持地址 0 的广播写入（FC05/06/15/16），广播不发送响应，其他地址的请求被忽略。主机界面暂不发送广播。
- 事件日志直接显示地址 + PDU + CRC 的完整原始 HEX、TX/RX、功能码和 CRC 状态。RTU 不显示 TCP 事务号。收到的错误 CRC 和不完整帧也保留供排查。

Modbus 事件表在级别与角色之间显示日志类型，包括 TCP 传输、RTU 传输、连接、监听、读取、写入、数据表、轮询、从机及异常等事件。点击时间表头切换升序或降序，上下图标高亮当前排序，默认最新记录在前。右键级别、类型、角色或对端表头，松开右键后打开多选筛选浮层，支持全选与清空选择；各列条件组合生效，筛选中的表头高亮。筛选仅改变显示，不删除记录，新到达的日志继续按当前条件筛选和排序。「清空日志」清除本页全部保留记录并重置筛选，清空前仍在后台队列中的日志不会重新出现；通信继续运行。

日志右侧是可调整宽度、独立滚动的报文面板。选中传输日志后显示原始十六进制、按协议字段用逗号分隔的原始二进制，以及字段 / 10进制 / 2进制表格。字段名称不显示括号说明，悬停字段可查看说明；鼠标在表格或原始数据上时，滚轮继续滚动整个报文面板。覆盖 FC01/02/03/04/05/06/15/16、异常响应、TCP MBAP 和 RTU CRC；二进制保留线上字节顺序，CRC 的十进制按低字节在前解释。读响应不携带起始地址，因此数据项按响应序号展示；位组保留 bit0 优先的打包方式。不完整、CRC 错误或未知功能的报文保留全部原始字节，并标注解析限制。

RTU 事务串行执行，已知功能码按长度组帧，接收间隔采用至少 20 ms 的容差以适应 Windows / USB 串口分片；不提供严格微秒级 t1.5 / t3.5 时序保证。同一串口不能同时被端点管理、主机或从机占用；RS-485 收发方向依赖适配器及驱动的自动切换能力。测试使用模拟串行端口验证协议和生命周期，尚未进行实际串口 / RS-485 硬件验证。

## 行为约定

- **流不是报文**：TCP / Serial 每条 RX 是一次读取片段。一次发送可能对应多次读取，多次发送也可能合并读取；需要协议层自行分帧。
- UDP 的 ONLINE 仅表示本地 socket 绑定成功，不代表对端在线。每条 RX 保留完整数据报；来源不限于配置的远端。
- Server 的 ONLINE 表示正在监听。客户端断开不会关闭监听器，发送必须选择在线 peer；不默认广播。超过 64 个在线客户端时拒绝新连接。
- UTF-8 查看中的 `␀ ␍ ␊ ⇥` 分别表示 NUL、CR、LF、Tab。无效 UTF-8 显示替代字符；跨读取片段的 UTF-8 字符可能被拆开，HEX 始终保留原始字节。
- 每次在 UI 重新连接时创建新会话并重新计数；直接复用核心会话 `ConnectAsync` 时统计累加。TCP 字节发送成功仅表示写入本机传输栈，不表示对端应用已处理。
- 发送最长等待 5 秒。流写入中取消或失败可能已经传输部分数据，因此关闭该流，避免在不确定的协议状态上继续发送。TCP Server 只关闭受影响的客户端。
- 周期范围为 50–3,600,000 ms；只有一个周期任务。启动时固定会话、peer、地址和内容；切换选中端点不改变目标。出错、关闭或点击「断开」会停止周期任务。不自动重连或重发。
- 接收通道容量 512，UI 每 100 ms 最多取 150 条；显示最多 1,000 条，日志最多 300 条。满队列丢弃最旧显示记录并计数，传输字节统计继续。接收队列和可见窗口不是无损抓包存储。
- 暂停只忽略显示，不停止 I/O，期间数据不会在恢复后补回。筛选匹配端点名、对端地址和当前模式下前 256 字节的预览。导出只包含当前筛选下仍保留的记录，但每条记录的 HEX 完整。
- CSV 使用 UTF-8 BOM、引用转义和文本公式前缀保护。可复制完整报文详情。
- Modbus 主机每个事务使用独立短 TCP 连接，不与原始 Traffic 会话共享接收者；Modbus 事件日志记录主机和从机的 TX/RX、对端地址、事务号、Unit、功能码及完整 HEX（含 MBAP）。报文直接在事件行内显示，可选择复制；异常响应和已收到的不完整报文也会保留。日志最多 300 条，后台队列容量 256，不作为无损抓包存储。从机监听独立端口，关闭软件时收拢所有客户端任务。

## 数据位置

主功能使用标签页导航。端点管理底部按事件日志、发送区、报文详情、使用说明排列标签，点击切换显示；串口名称可以直接输入，也可以从发现列表选择并手动刷新。Modbus 主从机模式采用高亮切换，寄存器 / 位表支持多个分区标签，新建时配置名称、类型、起始地址与数量，右键标签可编辑或关闭。寄存器标签配置暂不跨启动保存。

```text
%LOCALAPPDATA%/CommunicationStudio/connections.json
```

保存端点参数，不保存自动连接指令或历史流量。启动时所有端点均不自动启动。先写临时文件再原子替换；损坏配置会显示错误，关闭时不会自动覆盖原文件，用户主动保存新工作区后才替换。事件日志目前保留在内存中；流量需手动导出。第一版不支持多个程序实例同时编辑同一配置。


测试覆盖 TCP 收发/EOF/重连、多客户端定向发送、UDP 数据报及空包、取消/失败/并发断开、并发发送完整性、阻塞发送取消、Modbus 响应分片/错误、配置保存及损坏输入，以及 WPF Dispatcher 上的流量更新、筛选、暂停、容量限制、关闭和横纵滚动条交互。串口依赖实际设备和驱动，未进行硬件验证；CAN 尚未接入硬件。当前不声明生产级硬件兼容性或长期无损记录能力。

数据转换器通过「工具 → 数据转换器」或 `Ctrl+2` 打开，默认置顶，可取消固定或最小化。输入在左、输出在右，类型或内容变化后后台自动转换；关闭窗口保留本次输入，重复打开复用已有窗口。转换以原始字节为中间表示：HEX/BIN/OCT 每字节固定为 2/8/3 位，DEC 是 0–255 字节列表，多字节整数使用 UInt16/Int32 等类型。数值列表以空格、逗号或换行分隔，可分别选择两侧大小端；文本编码不添加 BOM，非法编码、溢出、长度不足直接提示并清空旧结果。Decimal 使用 .NET 的 16 字节 lo/mid/hi/flags 表示，细节见窗口提示。

校验码计算与数据转换器是独立顶层工具窗口，可通过任务栏或 Alt+Tab 切换，主窗口最小化不会隐藏它们。默认置顶，取消固定后可与其它应用正常叠放；退出 Communication Studio 时关闭全部工具。数据转换错误提示和字节计数支持实时中英文切换。
